# **T10: Chatbot Using Generative AI Techniques**

---

## **Objective**
This tutorial demonstrates the implementation of a generative AI-based chatbot using the Cornell Movie-Dialogs Corpus. The goal is to train a sequence-to-sequence model with LSTM layers for generating human-like responses in a conversational context. The training process is monitored using loss curves, and the model's performance is evaluated based on generated dialogue.

---

## Key Features
- **LSTM-based Sequence-to-Sequence Model** for dialogue generation.
- **Data Preprocessing**: Tokenization and cleaning of the Cornell Movie-Dialogs Corpus.
- **Training**: Optimized using Adam optimizer, with loss tracking over 50 epochs.
- **Inference**: Real-time text generation using the trained model for user inputs.
- **Loss Visualization**: Displaying loss curves during training to monitor progress.
- **Model Evaluation**: Sample dialogue generation before and after training to assess model's conversational quality.

---

## Usage
- Run the provided notebook to train the chatbot model on the Cornell Movie-Dialogs Corpus.
- Monitor the training progress with loss curves and evaluation metrics.
- Test the chatbot's performance by providing real-time input and generating responses from the trained model.
