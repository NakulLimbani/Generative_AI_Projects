# **T6: Fine-Tuning a Transformer Model on Wikipedia Text Corpus**

---

## **Objective**
This tutorial demonstrates the implementation and fine-tuning of a **pre-trained Transformer model (GPT-2)** on the **Wikipedia text corpus**. The goal is to enhance text generation capabilities by adapting a Transformer model to domain-specific text data. The training process is monitored using loss curves and evaluation metrics.

---

## **Key Features**
- **GPT-2 fine-tuning** on the **Wikipedia dataset**.
- **Efficient tokenization and preprocessing** of textual data.
- **Training with AdamW optimizer**, learning rate scheduling, and gradient clipping.
- **Loss visualization** for monitoring fine-tuning progress.
- **Text generation before and after fine-tuning** to analyze improvements.
- **Evaluation using Perplexity Score** to assess language modeling performance.

---

## **Usage**
- Run the provided notebook to **fine-tune GPT-2** or evaluate the pre-trained model.
- Monitor **training progress** with loss curves and evaluation logs.
- Inspect **generated text** at different training stages.
